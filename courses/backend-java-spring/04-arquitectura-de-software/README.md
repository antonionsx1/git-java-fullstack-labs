# 04. Arquitectura de software

Este módulo refuerza la teoría de arquitectura con decisiones aplicadas a un backend Java y Spring.

1. [Fundamentos de arquitectura](01-fundamentos.md): arquitectura frente a diseño, atributos de calidad y tradeoffs.
