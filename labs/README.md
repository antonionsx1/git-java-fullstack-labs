# Retos prácticos

Completa cada reto en una rama y abre un PR.

1. **Selección parcial:** separa cambios con `git add -p`.
2. **Historial limpio:** corrige tres commits con rebase interactivo.
3. **Conflicto semántico:** combina dos soluciones válidas y agrega una prueba.
4. **Reversión:** integra un defecto y reviértelo mediante PR.
5. **Recuperación:** pierde commits en una rama y usa reflog.
6. **Bisect:** identifica una regresión entre ocho commits.
7. **Release:** publica v1.0.0 y v1.0.1.
8. **CI:** provoca un check rojo y restáuralo.
9. **[Backend: el último cupo](09-backend-cupos/README.md):** verifica la inscripción concurrente con Spring Boot y PostgreSQL.
10. **[Fundamentos de Java](java-fundamentos/README.md):** practica POO, algoritmos, estructuras de datos y archivos.

## Bitácora del PR

- ¿Qué hipótesis probé?
- ¿Qué comandos ejecuté y qué observé?
- ¿Qué error cometí?
- ¿Cómo lo recuperé?
- ¿Qué haría distinto en producción?
