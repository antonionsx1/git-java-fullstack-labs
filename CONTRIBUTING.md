# Contribuir

1. Parte de `main` actualizado.
2. Usa una rama corta con prefijo semántico.
3. Mantén commits atómicos y Conventional Commits.
4. Ejecuta `cd app && mvn verify`.
5. Abre un PR con la plantilla completa.
6. Resuelve conversaciones y espera checks verdes.
7. Integra mediante squash salvo razón documentada.

No hagas force push sobre ramas ajenas. En una rama propia reescrita usa exclusivamente `--force-with-lease`.
